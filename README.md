# Some Teams

**Some-teams** is a simple web project built as part of my studies at [Yrgo](https://www.yrgo.se/), where I'm currently studying to become a **Fullstack Developer**.  
The website showcases information about various European football teams, their leagues, UEFA rankings, and related details.

---

## About the Project

The project consists of a small dynamic website built with **HTML**, **CSS**, and **PHP**.  
It demonstrates basic dynamic data rendering using PHP arrays and pages with shared components like headers, navigation, and footers.

### Pages:
- **Home page (index.php):**  
  Displays a list of 18 football teams with their logos, countries (extracted from the league name), and UEFA ranking.
  
- **About page (about.php):**  
  Includes information about the creator of the site.

---

## How It’s Built

- **Languages:** HTML, CSS, PHP  
- **Styling:** Custom CSS (Flexbox-based layout)  
- **Data Source:** `data.php` (PHP array with all team data)  
- **Tools Used:** Visual Studio Code, Git, GitHub
